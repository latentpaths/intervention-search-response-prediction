# Data sources and rights

The sources were retrieved on 25 September 2026; the source URLs and exact SHA-256 checksums identify the snapshots used. These files contain publicly measured perturbation responses, used for retrospective replay. They are retrospective inputs, not new wet-lab data.

- `tcell-cytokine-screens/responses.json.gz`: six IL2/IFNG screens from Supplementary Table 1 of Schmidt et al., DOI [10.1126/science.abj4008](https://doi.org/10.1126/science.abj4008), retrieved from the [BioGRID ORCS archive](https://orcs.thebiogrid.org/Dataset/712). Each record retains the published gene-level log2 guide enrichment, guide count, modality/context in the parent screen, and an empty replicate-ID list because this table does not contain donor-specific effects. Public HGNC gene-family annotations are joined by exact symbol; missing or renamed symbols receive no family annotation. Source URLs and SHA-256 hashes are embedded in the JSON. The gzip archive preserves the original JSON bytes; frozen checksums refer to the decompressed contents.
- `k562-combinations/pooled-counts.npz`: pooled raw UMI counts and retained cell counts, aggregated from the original filtered count matrix in [GSE133344](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE133344). No model-generated values are used.
- `k562-combinations/metadata.json`: original gene identifiers, perturbation identities, per-perturbation technical GEM-group cell counts, exclusions, source checksums, and the compact count archive checksum. Cell filtering uses the source `good_coverage` and `number_of_cells` flags; guide identity halves must agree. Technical processing groups are not biological replicates.
- `<dataset>/raw/`: ignored, recoverable upstream downloads. The 1.13GB compressed Norman matrix is streamed and hashed without retaining a local copy. The original genome-wide count dimensions are preserved in the compact archive; the eight-gene evaluation panel is selected later from disclosed singles only.

See [methods](../docs/methods.md) for preprocessing, eligibility, action/probe splits, units, and inference rules. Source papers retain their respective rights; availability of data does not transfer the repository's software license to their articles or supplementary materials. HGNC data are public-use nomenclature data; retain source attribution when redistributing derived annotations.

The 39 Boolean models are in `boolean-models/`. Their [source notice](boolean-models/README.md), manifest, and MIT license preserve the published filenames and source checksums.
